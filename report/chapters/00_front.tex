\section*{System at a glance}
VisionGuard is a web service that estimates whether an uploaded image was made by a generative
model or taken with a camera. The data comes from a Kaggle dataset, which I audited and cleaned and
then versioned with DVC on DagsHub. A \texttt{tf.data} pipeline feeds two Keras models, a CNN
trained from scratch and a fine-tuned MobileNetV2, and every run is tracked in MLflow on DagsHub.
The best model is registered with the alias \texttt{champion} and served by a model API container
on an Azure VM behind HTTPS. A Flask web app, which runs in Docker Compose with a PostgreSQL audit
trail, calls that API.

\section*{Disclosure of AI assistance and tutorials}
I used an AI assistant, Claude (Anthropic), a lot in this assignment. Claude wrote most of the code
in the repository (data scripts, training and tracking code, the Flask app, the API, Dockerfiles,
Compose files, the CI workflow and the Colab notebooks), and I reviewed it. Through the Claude
desktop app it also operated my browser to run the Colab notebooks, create the GitHub and DagsHub
repositories and set up the Azure VM from Cloud Shell, while I signed in to each service, created
the access tokens and entered every secret myself. Claude drafted the explanations in this report,
and I checked them against my results and edited them. All numbers, tables and plots come from the
actual runs: the project scripts write them from MLflow and the evaluation code, so none of them
were typed in by hand.

Documentation I used: the TensorFlow/Keras guides (\texttt{tf.data}, transfer learning) and the
MLflow, DagsHub, DVC, Docker/Compose, GitHub Actions and Azure documentation.
